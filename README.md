# 📖 About AVAY

**AVAY** is an intelligent student companion designed to simplify attendance management and academic planning.

Whether you're tracking lectures, planning your timetable, calculating attendance goals, or analyzing your academic performance, AVAY keeps everything organized in one beautiful and easy-to-use platform.

---

# ✨ Key Features

## 📅 Smart Timetable
- Weekly timetable management
- Subject scheduling
- Faculty & classroom details
- Easy editing

## ✅ Attendance Tracking
- One-tap Present/Absent
- Subject-wise attendance
- Daily attendance history
- Automatic attendance calculation

## 📊 Analytics Dashboard
- Attendance percentage
- Performance insights
- Monthly reports
- Interactive charts

## 🎯 Attendance Goal Planner
- Target attendance calculator
- Classes required to achieve target
- Safe bunk prediction

## ☁ Cloud Sync
- Firebase integration
- Secure data storage
- Backup & Restore

## 📄 Reports
- Export attendance
- CSV Reports
- PDF Reports

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/hmbholamajhi-eng/AVAY.git
```

### Navigate to Project

```bash
cd AVAY
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```
